# Figuring Out Content Intelligence

Independent content intelligence analysis for the Figuring Out podcast ecosystem.

## Project Goal
To analyze content performance patterns, build guest intelligence capabilities, and identify growth opportunities for India's #1 business podcast.

## Data Sources
- YouTube Data API v3 (public metadata: views, likes, comments, duration)
- Manual tagging for guest names, categories, and topics

## Data Dictionary
| Column | Description | Source |
|--------|-------------|--------|
| video_id | YouTube video ID | YouTube API |
| title | Episode title | YouTube API |
| published_at | Upload date | YouTube API |
| views | View count | YouTube API |
| likes | Like count | YouTube API |
| comments | Comment count | YouTube API |
| duration | Video duration (ISO 8601) | YouTube API |
| description | Video description | YouTube API |
